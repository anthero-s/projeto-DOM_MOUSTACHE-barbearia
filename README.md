# ✂️ Dom Moustache | Barbearia & Estilo

Integrantes:
Anthero
Pietro

Projeto acadêmico desenvolvido para a criação de um site responsivo de barbearia, permitindo a visualização de serviços e o agendamento de horários em tempo real.

---

## 📌 Sobre o Projeto

O **Dom Moustache** é uma aplicação web interativa desenvolvida com foco em **HTML5 Semântico**, **CSS3**, **Bootstrap 5** (gerenciado via **npm**) e **JavaScript puro (Vanilla JS)** para manipulação dinâmica do DOM.

A aplicação foi projetada seguindo os princípios de design responsivo (_Mobile-First_) e conta com uma identidade visual moderna inspirada em barbearias clássicas (Dark Theme com destaques em amarelo/dourado).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Customizações e ajustes finos de estilo.
- **Bootstrap 5:** Sistema de Grid responsivo, utilitários visuais, navegação colapsável e formulários estilizados.
- **Node.js / npm:** Gerenciamento de dependências do projeto (Bootstrap instalado sem o uso de CDN).
- **JavaScript (ES6+):** Manipulação dinâmica da interface para criação e remoção de agendamentos na tela sem recarregar a página.
